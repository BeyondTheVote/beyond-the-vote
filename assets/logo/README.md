# Campaign logo — Forward Wordmark

Logo direction 02, “Forward Wordmark,” is the selected identity. The website uses a fast, accessible HTML-and-CSS version of the mark: an upward-right arrow beside a two-line editorial wordmark.

Keep at least these versions:

- A full-color SVG for the website and large-format printing.
- A white SVG for dark backgrounds.
- A square PNG for social profiles.

`logo-options.html` remains as a record of the three explored directions and clearly marks option 02 as selected.

`social-preview.png` is the approved-direction sharing card at 1200 × 630 pixels. Its final `og:image` metadata should be added after the public GitHub Pages URL is confirmed, because social platforms require an absolute public image URL.
