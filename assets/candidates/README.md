# Candidate photographs

Add the final candidate photographs to this folder.

For good mobile performance:

- Prefer WebP files.
- Crop photographs to a 4:5 portrait ratio.
- Aim for 1200 × 1500 pixels.
- Keep each file below approximately 300 KB when possible.
- Use simple lowercase filenames such as `jane-doe.webp`.

After adding an image, update the matching `image` value in `js/data.js`, for example:

```js
image: "assets/candidates/jane-doe.webp"
```
